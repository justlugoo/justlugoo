## Construyendo ahora

**IQ Platform (proyecto de grado).** Plataforma para aprender a armar la mesa de Mayo, la mesa del instrumental quirúrgico, fuera del laboratorio. La construyo con dos compañeros de Ingeniería y con estudiantes de Instrumentación Quirúrgica, que aportan el contenido. Soy líder técnico y de planificación. Tiene tres módulos:

- **SIMIQ3D:** visor 3D de la mesa de Mayo con un chat. Backend en Python y FastAPI, con un modelo local en Ollama.
- **DataIQ:** API de técnicas quirúrgicas documentadas por los estudiantes de Instrumentación Quirúrgica. El MVP cubre 5 técnicas de Cirugía General. Escribí la primera etapa del backend.
- **SIVRI:** módulo de visión artificial con YOLO, en diseño. El diseño es mío.

**FinCapX.** App de escritorio multiplataforma para finanzas personales, con contabilidad por partida doble y soporte multimoneda. Hecha con Rust y Tauri. En desarrollo.
